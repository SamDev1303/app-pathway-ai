## Attribution notes

- CC BY-SA requires attribution + same-license sharing of modifications. Safe for in-app usage with a credits screen.
- Public Domain image (#4) has no attribution requirement but courtesy credit is included.
- When displayed in-app, include photographer name + license in a Credits / About screen, e.g. "Photo: Diliff, CC BY-SA 3.0, via Wikimedia Commons".
- For maximum derivative freedom (e.g. heavy editing without ShareAlike), consider swapping CC BY-SA entries for CC BY or PD alternatives before production.
